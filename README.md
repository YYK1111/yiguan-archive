# 衣冠藏卷

从古籍中的服饰词出发，逐步展开其历史形态、图像、制度与演变的数字人文展示平台。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

访问 `http://127.0.0.1:3000`。

## 构建与部署

```bash
npm run build
npm start -- -H 127.0.0.1 -p 3000
```

阿里云服务器由 PM2 运行 Next.js，并通过 Nginx 对外提供访问。

## 协作约定

1. 从 `main` 拉取最新代码。
2. 为每次修改创建独立分支。
3. 修改后执行 `npm run build`。
4. 通过 Pull Request 合并，避免直接覆盖他人的工作。

历史图像与古籍材料必须保留来源信息。无法确认作品名称、年代、馆藏或版权时，应明确标为待核材料，不作确定结论。

## 当前限制

投稿与审核接口仍为演示内存数据，服务重启后会恢复默认状态；正式多人录入前需要接入持久化数据库和图片存储。
